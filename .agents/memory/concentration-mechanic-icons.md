---
name: Concentration mechanic icons
description: Concentration mode logos should explain the actual exercise mechanics through standalone animated SVG shapes.
---

Use independent SVG compositions rather than library glyphs or square icon containers: Signals shows multiple colored distractor signals with one orange target, Tracking shows multiple moving circles with only one orange target, and Search shows a field of objects with one distinct target.

**Why:** The mode picker is more understandable when its visual language matches the interaction the user will perform, and square backplates hid that distinction.

**How to apply:** Keep the logo itself free of card backgrounds, borders, and decorative underlines; scale the SVG directly for compact and large contexts.
